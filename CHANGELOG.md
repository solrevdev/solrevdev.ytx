# Changelog

All notable changes to ytx are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/). GitHub Releases carry the full commit notes.

## [Unreleased]

## [1.2.0] - 2026-10-08

### Added

- `chapters`: chapters read from the video description as `{start, end, title}`, using YouTube's rules (starts at `0:00`, at least three, increasing, each at least 10 seconds, one block). Filled with `--metadata-only` too ([#16](https://github.com/solrevdev/solrevdev.ytx/issues/16)).
- The Markdown `transcript` and `--format md` have a `## Title` heading at each chapter.

## [1.1.0] - 2026-10-08

This release fixes the caption bugs from the v1.0.7 review ([#3](https://github.com/solrevdev/solrevdev.ytx/issues/3)) and settles the JSON contract.

### Breaking

- `url` is now the canonical watch URL, not the input echoed back.
- With no transcript, `transcript` and `transcriptRaw` are empty instead of holding placeholder text. Check `captionStatus`.
- Caption failures other than YouTube and HTTP errors now exit 1 instead of being reported as "no captions".

### Added

- Output fields: `videoId`, `channel`, `channelId`, `uploadDate`, `durationSeconds`, `viewCount`, `keywords`, `captionStatus` (`ok`, `none`, `skipped`, `blocked`, `error`), `captionLanguage`, `captionLanguageName`, `captionIsAutoGenerated`, `captionError` and `segments`.
- Exit code 3 when metadata is written but captions were blocked or failed, and 130 for Ctrl+C.
- `--format md|txt|srt|vtt` to write only the transcript.
- `--segments` for `{start, end, text}` with millisecond times.
- `--list-languages` to list a video's caption tracks.
- `--proxy <url>` for http, https and socks proxies. `HTTPS_PROXY` is documented.
- `--timeout <seconds>`.
- A stderr warning when no track matches `--language` and ytx falls back, and when `--language` is used with `--metadata-only`.
- NuGet package icon, symbols package (`.snupkg`) and SourceLink metadata.
- `LICENSE` file, Dependabot and a CodeQL workflow.

### Fixed

- Human-written captions are preferred over auto-generated ones.
- Short language codes match exactly or by prefix, so `-l fr` no longer returns Afrikaans and `-l pt` finds `pt-BR`.
- `&nbsp;` is replaced before whitespace is collapsed, so no double spaces remain.

### Changed

- YoutubeExplode 6.6.2, which removes the AngleSharp `NU1902` advisory.
- GitHub Actions are pinned to commit SHAs, and tests run on .NET 8, 9 and 10.

### Removed

- The stale `docs/html-viewer-feature.md`.

## [1.0.8] - 2026-10-08

### Changed

- JSON uses source generation and streams to stdout, which makes startup faster and allocates less.
- Transcript building no longer allocates for every caption.
- Trim and AOT analyzers run in every build.

## [1.0.7] - 2026-08-24

### Changed

- Releases use NuGet Trusted Publishing instead of a stored API key.

## [1.0.6] - 2026-07-16

### Added

- Tests for command-line parsing and formatting.

## [1.0.5] - 2026-07-16

### Added

- `--help`, `--version`, `--url`, `--language`, `--metadata-only` and `--compact`.

## [1.0.4] - 2026-07-16

### Changed

- Modernized the NuGet publishing workflow.

## [1.0.3] - 2025-11-17

### Added

- .NET 10 target.

### Changed

- YoutubeExplode 6.5.6.

## [1.0.1] - 2025-08-30

### Added

- First release: title, description, raw transcript and Markdown transcript as JSON.
